# 例も撮れない宣言も持たない `Sketch` の公開メンバの許容一覧 (#2116)。
#
# **既存の穴を載せて、検査を緑のまま通すための一覧で、減る方向にしか動かない。**
# 読むのは scripts/example-shots.py (make example-shots-check)。書き方・見る範囲・赤に
# なる条件は、そのスクリプトの冒頭が正典で、ここには写さない。
#
# 手を入れるのは次の 2 つだけである。
#
# - 例か撮れない宣言を付けた口の行を **消す** (消さないと検査が赤になる)
# - 口の綴り (引数の型) を変えた・口を消したときに、その行を書き直す・消す
#
# **新しい口をここへ足さない。** 足せば検査は緑になるが、足すことで穴が増える。
# 例を足せない理由があるなら、口の説明文の下に `// shot: 撮れない <理由>` と書く。
# 例と囲みは書けるが Gyazo の鍵が無くて撮れないだけなら、`// shot: 後で撮る` で通る。
#
# 1 行 1 口で、`ファイル: 名前 (引数の型, …)`。# で始まる行と空行は読まない。
# 並びはソースの順 (ファイル名、その中の宣言の順)。
