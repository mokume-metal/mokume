合成した音を、鳴るたびに作って捨てても、65 個目から鳴らなくなることが無くなりました。手放して (変数や配列から外して) 鳴り終えたオシレータとノイズは、同時に生きていられる 64 個の数から外れ、置き場が次の音に使われます。鳴り終えたとは、`stop()` で止めて消えたか、`Env` の形が終わって無音になったことで、手放しても鳴っている音は切らず、鳴り終えてから数から外れます。たとえば壁に当たるたびに `createTriOsc()` で作り、`Env.play(osc, 0.005, 0.05, 0.6, 0.3)` で鳴らして手放す書き方が、何百回でも鳴ります。包絡なしで `play()` したまま手放した音は鳴り続けて数から外れず、エフェクト (リバーブ・ディレイ・濾波器) は今までどおりスケッチの終わりまで残ります。エフェクトに通した音が先に鳴り終えて数から外れても、エフェクトの尾 (残響・反響) は切れません。同時に生きている音が 64 個を越えたときの振る舞い (作れない音は鳴らず、1 度だけ知らせる) は変わりません。`setup()` で作って使い回す書き方も、今までどおり使えます。
