`make catch-up` が、**衝突を 1 つも解いていない取り込みまで push してしまう**ことがあったのを直した。push の要否は取り込みの時点で決まるようになり、手元の検査が走っている数分の間に main へ別の PR が入っても判定は動かない。以前は検査の後に「いまの main」と比べ直していたので、その間に main が動くだけで「衝突を解いてある」と誤って読み、承認が要る PR は押し直しになっていた。

あわせて、検査の最中に main が動いて手元の実行の覆いが古くなった場合は、queue へ戻す前にそれを名乗って止まるようにした。以前はそのまま queue へ入り、弾かれてから理由を探すことになっていた。
