区画へ置かれる JSON (観測の目録・入力とつまみの応答・作り直しの記録・差し出す面の目録) の鍵が、どの面でも辞書順で並ぶようになった。あわせて、応答を置けなかったことが黙って捨てられなくなった。

これまでは面ごとに書き方が割れていて、`.sortedKeys` を付けていない面では `JSONEncoder` が辞書の走査順で書くため、**同じ内容でもプロセスごとに並びが変わっていた** — 差分を取って読む人と道具に効く。失敗のほうも、観測の目録は置けなくても標準エラーに 1 行も出なかった。いまはどの面も 1 度は名乗る (同じ置き場所で言い続けはしない)。
