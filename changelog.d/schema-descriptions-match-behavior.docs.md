観測の応答 (`Schemas/observe-report.schema.json`) の `contentFraction` の説明を直した。「左上の画素と違う色を持つ点の割合」と書いていたが、実際は**地 (いちばん多い色) と違う色を持つ点の割合**である。左上を地に取る定義は「左上に図形を置いた絵で内容が 9 割になる」ため実装が退けたもので、説明だけが古い定義を名乗り続けていた。**値は前から多数派の色を基準に数えており、変わっていない** — 変わったのは説明のほうなので、左上基準だと信じて数値を解釈していた読み手は読み方を改める必要がある。

あわせて同じスキーマの 3 件を実装の振る舞いに合わせた。応答の上の階の `stats` は「1 枚も採れなかったとき」ではなく **`image` と同じ条件 (宣言した枚数が揃わなかったとき)** で省かれる。`load.frameRate` と `load.frameTimeMs` は「まだ測れていない」ときだけでなく、**しばらくフレームが進んでいないとき**にも省かれる (止めている間に古い数字を名乗らないため)。

出る JSON の形も値も変わらないので `schemaVersion` は据え置き。
