`beginRecord()` で書いた `.mov` について、2 回書き出して何が一致するかの説明を正した。以前のリリースノートと説明は「ProRes 4444 はファイルのバイトまで一致した」と書いていたが、一致するのは**デコードした画素と時刻**である。容れ物に刻まれる作成・更新時刻には書き出した時刻の秒が入るので、違う秒に書いた 2 本を `shasum` で比べても同じにはならない。同じ動きが出たかは、デコードした画素と時刻で比べる。振る舞いは変わっていない。
