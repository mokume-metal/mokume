観測の `every` の説明を、実際の時計に合わせました。`mokume run` / `watch` で走っているスケッチは実時計で動くので、**撮れた枚の時刻の間隔は揃いません** — 撮っている間は絵の書き出しでフレームが重くなるぶん、間隔が伸び縮みします。動きを並べ直すには、応答の目録 (`frames`) の各行が持つ `time` を読んでください。枚数のまま並べると速さの狂った動きになります。

これまでの説明は「間隔をフレームで数えれば、同じスケッチを 2 回走らせれば同じ列が返る」と言っていました。それが成り立つのは時計をフレーム番号から導く経路 (`SketchRuntime` を直接組むヘッドレスの走らせ方) だけで、観測が覗く窓の経路ではありません ([#1285](https://github.com/mokume-metal/mokume/issues/1285))。
