async の `main` の上で `SketchRuntime` を自分で回すプロセスが、30 秒走り続けた後にメニューバーへ名乗ったところで、出来事が届くと終了コード 0 で終わりうるのを直しました。名乗りが `NSApp` の走っていないところで出来事を汲み出すとき、main の run loop を別の誰かが回していても汲み出しを始めていたためです。いまは main の run loop が走っているときは汲み出さず、名乗りだけを出します。代償として、その形ではメニューバーの名乗りのメニューは開けず、プレビューも動きません (窓を開く経路と、同期の `main` で回す経路は今までどおり開けます)。名乗りのメニューが開いている間に「誰も進めていないか」を測る時計も、検査で差し替えられる作者の時計ではなく実時間にそろえました。
