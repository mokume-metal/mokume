視点と投影の 7 口 (`camera` ×2 / `setCamera` / `perspective` ×2 / `ortho` ×2) に、引数を 1 つずつ動かした例と絵を 8 枚付けた。投影の 4 枚は同じ 3 つの立方体を写しているので、透視では奥ほど小さく (幅 90 / 74 / 63 画素)、平行では 3 つとも同じ (75 / 75 / 75 画素) であることを並べて比べられる。`setCamera` の絵は、1 つのフレームの中で 2 つの視点が使えることを示している。

あわせて `perspective(_:_:_:_:)` の `fieldOfView` の説明を直した。「広げるほど遠近が強く出る」と書いていたが、**視点を動かさずに画角だけ変えても遠近の強さは変わらない** — 手前と奥の大きさの比は、既定の画角でも 1.6 に広げても 1.43 倍で同じだった。変わるのは写る範囲と、そのぶんの大きさである。
