`mokume render` が、何も書き出せていないのに `Wrote … frames` と名乗って 0 で終わることがなくなりました。道具と依存の mokume の版がずれたときなどに、スケッチが書き出しの頼みを読めずに窓を開いて終わっていたためです。頼みの値が読めない・書き出せない組のとき、スケッチは窓を開かずに理由を標準エラーに出して 0 以外で終わります。さらに、スケッチが 0 で終わった後に、道具が書き出し先を確かめます。`.mov` は映像の枚数が、連番はファイルが、頼んだ枚数ぶん揃っていること (この回に書かれたものだけを数えます) を見て、足りなければ「N 枚中 M 枚」のように名乗って 0 以外で終わり、`Wrote …` の行は確かめた後にだけ出します。
