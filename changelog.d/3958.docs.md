`JSONObject.getInt(_:)` と `JSONArray.getInt(_:)` の説明に、JSON の数の値は `JSONSerialization` が返した値で整数かを決めるので、読み込みの時点で端数や下位の桁が失われる場合があると書き足した。`9007199254740993.0` は、数の値なら 9007199254740992、文字なら桁のまま 9007199254740993 になる。正確な整数が要るときは文字で渡す。
