押した・離した・クリックしたを**出来事として**受け取れるようにした。スケッチに `mousePressed()` / `mouseReleased()` / `mouseClicked()` を書けば呼ばれる (Processing / p5.js と同じ綴り)。書いていないスケッチは今までどおり動く。

これまで読めたのは「いま押されているか」(`isMousePressed`) だけで、押した瞬間は前のフレームとの差から自分で作ることになっていた。**1 フレームに収まった押下だけは、その形でも書けなかった** — 溜まった出来事はフレームの頭で「いまの状態」へ畳まれるので、`mouseDown` の直後に `mouseUp` が来ると押されたことがどこにも残らない。外から送る経路 (`.mokume/input`) では 1 回の要求がまとめて 1 フレームへ入るため、クリックを 1 件送るという最も素直な使い方が常に消えていた。

畳むのをやめたわけではなく、**1 件当てるごとに配る**ようにした。コールバックの中で読む `mouseX` / `mouseY` / `isMousePressed` / `mouseButton` は、その出来事を当てた直後の値になる。`draw()` から見える最終状態は今までと変わらない。窓での実操作と外から送った出来事は、同じ並びなら同じ呼び出しの並びを生む。
