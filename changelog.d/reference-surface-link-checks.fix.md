参照の面を指す手書きのリンクが、面の名前と食い違ったまま残らなくなった。これまで機械が見ていたのは面の出力の中だけで、トップページの「参照の面」リンクと README の URL は**誰も見ていなかった**ため、面の名前が変われば押した人が 404 に当たるのに CI は緑のままだった。中間の 1 枚に対する判定は在ったものの、面の名前が SPDX ヘッダ・題・リンクの文字列にも現れるせいで**行き先を架空の名前に変えても通ってしまい**、実際には一度も行き先を見ていなかった。3 か所とも、行き先の名前の節を取り出して面が名乗る名前と突き合わせる。
