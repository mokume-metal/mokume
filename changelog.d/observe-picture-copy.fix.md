MCP の `observe` が返す絵の場所が、別の書き手の撮影で書き換わらないものになった。窓口は絵を自分の一時の置き場へ写し、写し終えた後に応答がまだ自分の要求のものであることを確かめてから、**区画の外にある写しの場所**を返す。以前は `.mokume/observe/` の中の場所をそのまま返していたので、別の書き手が同じ区画で撮り始めると、呼び手が読む前に同じ名前で別の絵へ入れ替わり、他人の絵を自分の絵として読む形になりえた。確かめられなかった回は、絵を返さず、取り合ったことと撮り直す手を答える。写しは直近の 4 回の観測の分だけ残り、窓口が終わると消える。区画の形と走っているスケッチ側は変わらないので、古い作品にも効く。撮影のスニペット (`scripts/observe_lib.py` の `copy_image` / `copy_images`) も、写してから確かめる。
