MCP の `observe` が返す絵の場所が、別の書き手の撮影で書き換わらないものになった。窓口は絵を自分の一時の置き場へ写し、写し終えた後に応答がまだ自分の要求のものであることを確かめてから、**区画の外にある写しの場所**を返す。以前は `.mokume/observe/` の中の場所をそのまま返していたので、別の書き手が同じ区画で撮り始めると、呼び手が読む前に同じ名前で別の絵へ入れ替わり、他人の絵を自分の絵として読む形になりえた。確かめられなかった (取り合った) 回は、絵を返さず、取り合ったことと撮り直す手を答える。写しは直近の 4 回の観測と絵の合計 120 枚の範囲だけ残り、窓口が終わると消える (信号で終わって残った置き場は、次の窓口の起動時に掃かれる)。本文の JSON の絵の名前も、返す場所の絶対の綴りになる。区画の形と走っているスケッチ側は変わらず、目録 (`frames`) を書く版のライブラリなら古い作品にも効く。それ以前の版は応答を消さずに絵を先に上書きするので、確かめが成り立たない — 写さずに区画の場所を返し、「次の要求までしか自分の絵でない・確かめられない」と名乗る。撮影のスニペット (`scripts/observe_lib.py` の `copy_image` / `copy_images`) も、写してから確かめる。
