光の口と `lights()` の説明に、Processing / p5.js と同じ指定から同じ明るさは出ないことを書きました。振る舞いは変わっていません。

素の数値で渡した光の色は、表示の目盛りで受けて**線形の値へ戻してから**掛けます。手本は表示の値のまま掛けるので、同じ数でも陰影は手本より明るく出ます。`lights()` の既定の光の組も手本と違い、底上げ・平行光ともに手本より明るく、斜め上から差します。

どちらも手本へは寄せません。手本に従うのは名前と引数の順序までで、同じ画素が出ることは約束しない、という線引きを ADR-0020 決定 1 に書き足しました。
