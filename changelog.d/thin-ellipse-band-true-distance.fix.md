細長い楕円の輪郭が、太さによって帯ごと抜けたり、内縁・外縁が最大 0.8 画素ずれたりしていたのを直した。`noFill()` の `ellipse(0, 0, 100, 6)` は `strokeWeight(4)` と `strokeWeight(5)` で長軸に沿って帯が丸ごと抜け、`strokeWeight(5.02)` 以上で急に出る、という境目の跳びもあった。`ellipse(0, 0, 84, 26)` に `strokeWeight(7)` を付けると内縁が最大 0.8 画素ずれていた。細長い楕円の輪郭を、縁からの近似ではなく真の距離で数えるようにしたので、太さを動かしても帯が滑らかに太る。塗りがあれば、抜けていた帯の所に塗りの色が出ることもなくなった。輪郭の内縁・外縁のずれが小さい楕円 (円や、細い輪郭の楕円など) は、これまでどおり近似で描くので絵は変わらない。
