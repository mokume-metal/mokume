`ambient` と `emissive` の絵 (色で渡す口と、素の数値で渡す 4 口) を、3 つの球を平行投影 (`ortho()`) で同じ向きから見る場面に撮り直した。透視のままだと球ごとに見る角度が違い、明るい点の位置も明暗の値も球の材質ではなく置き場所で変わっていた。`ambient` の絵は周りの光を `emissive` の絵と同じ強さに揃え、左の球が頭打ちせずに同じ球から始まるようにしたうえで、「陰の側がどこまで落ち、明るい側がどれだけ下がるか」の数を画素を測った値に直している。
