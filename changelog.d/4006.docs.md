資材の置き場として見るのは `Sources/<名前>/assets` だけであることを、`mokume watch` の help と、`mokume new` が置く `Sources/<名前>/assets/README.md` に書いた。`path:` で動かした target の置き場や `src/` の下の `assets` は、資材の宣言の抜けの検査も `mokume watch` の見張りも対象にしない。その置き方では、宣言の抜けは実行時に絵が読めないまで分からず、そこで保存しても作り直さない。挙動は変わらない。
