資材の置き場として見るのは `Sources/` の直下のディレクトリの `assets` (`Sources/<名前>/assets`) だけであることを、`mokume watch` の help と、`mokume new` が置く `Sources/<名前>/assets/README.md` に書いた。`path:` で `Sources/` の外へ動かした target の置き場・`src/` など別の名前の置き場の下・入れ子 (`Sources/<名前>/<下>/assets`) の `assets` は、資材の宣言の抜けの検査の対象にならず (抜けは実行時に絵が読めないまで分からない)、`mokume watch` の下で保存しても作り直さない。ただし target が置き場の直下の `assets` を `.copy` で宣言していれば、中の `.metal` の断片は走らせたまま差し替わる。`path:` で `Sources/` の下へ動かした target の `assets` は範囲の内で、help・ガイド・DocC の「`path:` を変えた target は範囲の外」を「`Sources/` の外へ動かした target」に正した。挙動は変わらない。
