`createShape { }` の中で次のことをすると、同じフレームに先に何か置いていれば形が空になり、中で描いたものがそのフレームへ描かれていた。いまは形が中で描いたものを持ち、中で描いたものはフレームに出ず、組み立ての前に置いたものは置いた時点のまま描かれる ([#1855](https://github.com/mokume-metal/mokume/issues/1855))。

- `noiseSeed()` / `noiseDetail()` で揺らぎの設定を書き換える (描き場所の上で `pg.noiseSeed()` と書いても)。抜けると外の設定へ戻る
- 同じフレームで先に置いた描き場所を描き換える。先に置いた所は描き換える前の絵で出て、形の中で置いた描き場所は形を置いたときの絵を読む
- 描き場所の `createShape { }` の中で、その描き場所の `endDraw()` を呼ぶ。そこでは閉じず、1 度注意して組み立ての出口でフレームを閉じる

あわせて、`noiseSeed()` / `noiseDetail()` はフレームの途中で描き切らなくなった。`loadPixels()` のような区切りにならないので、決め直しの前に置いた面にも後に置いた立体の影が落ちる。置いた図形はどこでも置いた時点の設定で引かれ、`setup()` で置いてから決め直した図形も、最初のフレームで置いた時点の設定のまま描かれる (これまでは最初のフレームを描いた時点の設定だった)。
