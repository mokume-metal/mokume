**`v0.7.0` で入った破壊的変更を、いま名乗ります。** 受け口を `Float` から広げた変更 ([#983](https://github.com/mokume-metal/mokume/pull/983)) には 2 つの影響がありましたが、`v0.7.0` のノートは前者を新機能の項目の中で触れただけで、後者には触れていませんでした。挙動は変えていません — 名乗り方と案内を直しています。

**1. `.pi` のような書き方は、型を名乗ります** ([#1017](https://github.com/mokume-metal/mokume/issues/1017))。渡す先が型を決めなくなったので、`.pi` だけでは `Float` と `Double` のどちらか決まりません。**コンパイルが通らなくなる**ので、その場で分かります。

```swift
rotateX(.pi)        // 通りません
rotateX(Float.pi)   // こう書きます
```

`Float(index) / Float(count) * 2 * .pi` のように**他の項が型を決めている式はそのまま通ります**。

**2. 整数だけで書いた割り算は、整数のまま計算されます** ([#1018](https://github.com/mokume-metal/mokume/issues/1018))。こちらは**コンパイルが通ってしまう**ので、描かれる絵で気付くことになります。

```swift
circle(x, y, 1 / 2)         // 直径が 0 になり、何も描かれません
circle(x, y, 1 / 2.0)       // 0.5 が渡ります
fill(255, 255 * 50 / 100)   // 127 になります (v0.6.0 では 127.5 でした)
fill(255, 255 * 50 / 100.0) // 127.5 が渡ります
```

**割り算を含む式は、片方に小数点を付けてください。** `width` や `time` のように面が返した数が式に入っていれば、全体が `Float` として計算されるのでそのままで構いません。

作者の読む面の「数の型」に、この 2 つを書き足しました。
