公開 API の一覧を版ごとに配るようにした。Release の資産 `mokume-api-<版>.md` に、その版の公開シンボルが署名つきで並ぶ — 利用者もエージェントも、**依存している版ぴったりの面**を引ける。一覧はリポジトリに置かず、要るときに組み立てる (`make api-list OUT=... VERSION=...`)。あわせて、公開 API が名前と面の規範 (ADR-0020) に沿っているかを機械で検査するようにした (`make api`。CI に入っている): オンオフの対になる綴り・二層で食い違う引数ラベル・下の層に重ねた説明文・文書へ直書きした件数を見つける。

参照スケッチを 3 本置いた (`swift run reference-sketches`)。図形とスタイル / 文字と画像と保持した形 / 画素と自分で書いた塗り。**利用者が書く形のまま並べてある**ので、面に穴があればここが書けなくなる。
