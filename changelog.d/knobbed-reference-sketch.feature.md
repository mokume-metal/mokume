参照スケッチに `knobs-and-values` が増えました。宣言した値・窓のつまみ・外からの書き込み・保存が 1 本のスケッチの中で全部使われているので、`swift run reference-sketches knobs-and-values` で走らせて引けば、つまみの往復をひととおり確かめられます。

範囲を書かなかった値 (`seed`) も 1 つ混ぜてあります。窓につまみは出ませんが、値は面に出ますし外からは書けます。
