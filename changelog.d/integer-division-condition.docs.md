**「Swift で 3 つだけ違うこと」の 2 番を、整数除算になる条件つきの説明に直しました。** 「整数だけの式は整数のまま計算される」と条件なしに読めましたが、整数のまま計算されるのは、渡す先が型を決めない口 (描く口・数の口) へ整数リテラルだけの式を渡すときです。`let r: Float = 1 / 2` のように型を名乗った文脈では、同じ式が 0.5 になります。例にその 1 行を足しました。公開の API は変えていません。
