**`shader()` / `texture()` の下で同じ形を続けて置いても、1 つずつ置いたときと縁の画素が 1 つも変わらなくなりました。** 続けて置いた `rect`・`ellipse`・`circle`・`arc` (`.pie`・一周・輪郭を引かない既定と `.chord`) と塗りだけの角丸の `rect` は、頂点をまとめて置く代わりに置き場所の変換を GPU で掛けます。これまでは位置の足し方の順が CPU と違い、輪郭つきの形や貼る絵の塗りで、縁の数画素の値が「同じ形が続くか・1 つだけか」で入れ替わっていました。GPU でも CPU と同じ順 (位置を足す → 回転と拡大 → 平行移動) で置き、貼る絵の読み取り位置も同じ箱から作るので、置き方によらず同じ絵になります。
