`pingpong` の `length` が大きいとき、小さな時刻が 0 に潰れなくなった。これまでは `pingpong(1, 100_000_000)`・`pingpong(2, 100_000_000)`・`pingpong(-1, 100_000_000)` がどれも 0 を返し、`pingpong(-10, 100_000_000)` は 16 を返していた。いまは周期の中の位置を丸めずに求めるので、それぞれ 1・2・1・10 が返り、負の時刻はいつも正の時刻と同じ値になる。負の `length` でも同じく `-1`・`-2` が返る。

あわせて、ごく小さな負の時刻もそのまま折り返す。`pingpong(-1e-9, 1)` はこれまで 0 だったが、正の側と同じ `1e-9` を返す。
