**`loadModel` と `textSize` を使い続けても、メモリが増え続けなくなりました。**

- これまでは、動きを書き出した連番の OBJ を `draw()` の中で 1 枚ずつ `loadModel` で読むと、読んだモデルが全部残っていました。
- `textSize(14 * pulse)` のように大きさを毎フレーム変えて字を描くと、大きさごとに書体が残っていました。

いまは、読み直さないための控えに上限があります。上限は面ごと (`createGraphics` で作った面もそれぞれ) で、しばらく使っていないものから捨てます。

| 控え | 上限 |
| --- | --- |
| モデル | 見積もりで約 64 MB |
| 書体 | 64 件 |
| 立体の形・稜線 (線を引いたモデルの稜線を含む) | 見積もりでそれぞれ約 16 MB (これまでは 64 件) |

上限を超える並びを繰り返し使うと、そのたびに作り直します。

- 上限を超える長さの連番を繰り返し回すと、毎回読み直します。繰り返し回すなら、`setup()` で配列へ読んで持ってください。
- 1 フレームに 64 通りより多くの大きさの字を描くと、毎フレーム書体を引き当て直します。大きさの種類を絞るか、同じ大きさで書いて `scale()` で伸ばしてください。
