`clip(_:_:_:_:)` が、矩形を**呼んだ時点の変換で面へ写して**読むようになりました ([#2721](https://github.com/mokume-metal/mokume/issues/2721))。これまでは `translate`・`scale` の後でも矩形を面の座標のまま読んでいたので、`translate(100, 0); clip(0, 0, 50, 50)` は x = 0…50 を切り抜きました。これからは、手本 (Processing) の既定の描き手と同じに x = 100…150 を切り抜きます。`scale(2); clip(10, 10, 20, 20)` は (20, 20)〜(60, 60) です。切り抜きが決まるのは呼んだ時点で、後から変換しても動きません。

あわせて、幅や高さが負の矩形を、手本と同じに裏返して読むようになりました。`clip(100, 100, -50, -50)` は、これまでは何も描かれず、これからは (50, 50)〜(100, 100) を切り抜きます。

直し方: 変換の下で `clip` を書いていたスケッチは、次のどちらかに直します。

- 変換の前に `clip` を呼ぶ (変換の外では、これまでと同じ面の座標のまま)
- 変換の下で呼ぶなら、面の座標で渡していた数を、変換の前の数へ直す (`screenX`・`screenY` で角を写して渡していたなら、そのまま渡す。写したまま渡すと変換が 2 度掛かります)。変換を効かせずに面の座標で切り抜きたいときは、`pushMatrix()` の中で `resetMatrix()` を呼んでから `clip` を書く

回転・剪断の下の `clip` は、写した 4 つの角を囲む面に沿った矩形で切り抜き、1 度だけ警告します (切り抜きは面に沿った矩形しか持てません)。90 度刻みの回転 (`rotate(.pi / 2)` の `Float` の丸めだけの差を含む) と鏡映しは正確に切り抜き、警告しません。1e-6 ラジアンほどの小さな本物の回転は、丸めではないので警告します。

説明文に、手本 (Processing) は `imageMode()` で数を読み、mokume は `rectMode(_:)` で読むことを足しました。手本で `imageMode(CENTER)` と組んでいた `clip(x, y, w, h)` は、角を渡す `clip(x - w / 2, y - h / 2, w, h)` と書き直してください (`rectMode(.center)` を合わせると `rect` や `text` の箱の読み方も変わります)。
