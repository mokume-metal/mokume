パーティクル (`particles`・`emit`・`force`) と画像 (`loadImage`・`requestImage`・`createImage`・`image`・`tint`) の API の説明を、一般的な技術用語で書き直した。Xcode のクイックヘルプとリファレンスで、「粒」「噴き口」「断片」「絵」「口」「枠」「資材」などの独自の言い回しが、パーティクル・エミッター・シェーダ・画像・API・スロット・アセットといった通常の用語になる。API の名前と挙動は変わらない。
