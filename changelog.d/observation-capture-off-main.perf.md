観測 (`mokume observe` や MCP の `observe`) で絵を撮る間、PNG の符号化とファイルの置き換えをフレームの外で行うようになり、撮る枚のフレームが止まらなくなりました ([#2381](https://github.com/mokume-metal/mokume/issues/2381))。これまでは撮る枚ごとに、読み戻しの後の PNG の符号化とファイルの置き換えを main で同期に行っていたため、4K 原寸の 1 枚で撮る間のフレームが約 44 ms 止まり (うち約 40 ms が PNG の書き込み)、観測が返す `frameTimeMs` にも撮影の負荷が混ざっていました。

観測の結果は変わりません。目録 (`report.json`) は全枚の書き込みが済んだ後に置くので、目録を読んだ時点で並んだ絵は全部ファイルになっています。書き込みに失敗した枚があれば、今までどおり `complete` を返さず理由を警告に載せ、目録はその枚の手前で終えます。次の撮影は、前の撮影の書き込みが済むまで始まりません。違うのは、目録が撮り終えたフレームの数フレーム後に出うることだけです (読み手は識別子が一致するまで待つので、読み方は変わりません)。裏で抱える枚数には上限があり、越えたら待つので、メモリは伸びません。
