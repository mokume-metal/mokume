`mokume new` が、AI エージェント向けの案内を 2 枚置くようになりました。`AGENTS.md` には道具の使い方 — **指示の対象が書かれていなければそのスケッチを指すこと**・絵や動きの話は `observe` を呼んでから答えること・動きは `count` を上げて続けて撮ること・絵が変わらない理由は `build_status` が持つこと・窓口が応えないときは `mokume doctor` を打つこと — が入ります。`CLAUDE.md` はそれを指す 1 行だけを持ちます (Claude Code が自動で読むのはこちらなので)。

**作り方・題材・進め方は書きません。** 渡すのは道具の構造から導かれることだけで、作品の側の運用はそのリポジトリのものとして残します。
