形 (`createShape`・`shape`) とグラフィックス (`createGraphics`・`draw(into:)`・`image`・`texture`) の API の説明を、一般的な技術用語で書き直した。Xcode のクイックヘルプとリファレンスで、「描き場所」「組み立て」「置き場所」「断片」「写し」「揺らぎ」「閉包」などの独自の言い回しが、グラフィックス・構築・配置・シェーダ・コピー・ノイズ・クロージャといった通常の用語になる。API の名前と挙動は変わらない。
