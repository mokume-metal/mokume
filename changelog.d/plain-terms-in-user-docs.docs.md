API リファレンスのトップページ・README・利用ガイドを、一般的な技術用語で書き直した。「面」「口」「描き場所」「粒」「揺らぎ」のような独自の言い換えを、キャンバス・API・オフスクリーンバッファ・パーティクル・ノイズなどの語に直している。説明している振る舞いは変わらない。トップページのいくつかの節の見出しも変わったので、節へのリンクを保存していた場合は新しい見出しから開き直してほしい (例: 「粒を飛ばす」→「パーティクル」、「手本の名前から引く」→「Processing・p5.js の名前から探す」)。
