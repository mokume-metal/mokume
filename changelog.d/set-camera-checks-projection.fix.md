`setCamera(_:)` に渡した `Camera` の投影を、`perspective(_:_:_:_:)` / `ortho(_:_:_:_:_:_:)` と同じ基準で検めるようになりました。写す範囲が潰れている (手前と奥の面が同じ距離・平行投影の左端と右端が同じ など)・画角が 0 以下か π 以上・横 ÷ 縦の比か手前の面までの距離が 0 以下・数でない値を含む投影は、注意を 1 度出して値を丸ごと捨て、それまでの視点のまま描き続けます。これまでは `perspective` / `ortho` なら断る値も `setCamera` では検めずに当てていたので、絵が丸ごと消えることがありました。

**横 ÷ 縦の比が負の透視も、`perspective` と同じく断られるようになりました。** v0.11.1 までは、`setCamera` で当てると画面の左右が裏返った絵で描いていました。左右を鏡映したいときは、`scale(-1, 1, 1)` で置くか、左端と右端を入れ替えた `ortho` を使います。
