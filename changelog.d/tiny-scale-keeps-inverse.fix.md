倍率が小さいだけの `scale` の下でも、`spacePosition` が元の点へ戻り、光の当たり方が変わらないようにした。

これまでは、一様に 0.0049 倍 (奥行きを含む 3 軸)・平面で 0.00034 倍・奥行きだけ 1e-7 倍を下回ると、潰れていない変換を「潰れた変換」とみなしていた。そのため `spacePosition` が (0, 0, 0) を返し、軸ごとに倍率が違う形 (`scale(0.01, 0.01, 0.001); sphere(4000)` など) や、その中で置いた `directionalLight` の向きで陰影が狂っていた。いまは、どこかの軸を 0 倍にした変換 (と、それと区別できないほど小さいもの) だけが潰れた変換として扱われる。
