リリースごとに配る公開 API 一覧 (`mokume-api.md`) の並びが、ソースの書き順で揺れなくなりました。これまでは同じ名前で引数の型だけが違う宣言 (`ambientLight(_:)` の色を渡す形と明るさを渡す形など) の並びが、宣言を書いたファイルの順にそのまま従っていたため、**公開 API が 1 つも変わっていないのに版の間の差分に行の入れ替わりが出る**ことがありました。同じ名前の宣言は引数の型の並びで順が決まるようになったので、版を並べて差分を取ったときに増減だけが読めます。
