シンボリックリンクを、更新時刻のたまたま同じ別のファイルへ付け替えたとき (または更新時刻を保った写しで `rename` して置き換えたとき、同じファイルを書き換えて更新時刻を `touch -r` などで戻したとき)、`loadImage` が前の絵を、`loadFont` が前の書体を返し続けていたのを直しました。つまみ・観測・入力の区画のファイル、記録・再生の資源のハッシュ、`run` / `watch --remote` のつまみの応答の見張りも同じで、新しい中身を読まずにいました。ファイルが変わったかを更新時刻だけで見ていたためで、状態変更時刻 (ctime)・大きさ・ファイル番号 (inode・ボリューム) も見るようにしました。読む手間は変わりません (`stat` 1 回)。権限や拡張属性だけを変えたときも 1 度読み直すようになります。HFS+・exFAT のように状態変更時刻を細かく持たないボリュームでは、その刻みの中で同じ大きさのまま書き換えて更新時刻を戻すと、引き続き見分けません。
