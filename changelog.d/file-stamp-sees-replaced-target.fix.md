シンボリックリンクを、更新時刻のたまたま同じ別のファイルへ付け替えたとき (または更新時刻を保った写しで `rename` して置き換えたとき)、`loadImage` が前の絵を、`loadFont` が前の書体を返し続けていたのを直しました。つまみ・観測・入力の区画のファイル、記録・再生の資源のハッシュ、`run` / `watch --remote` のつまみの応答の見張りも同じで、新しい中身を読まずにいました。ファイルが変わったかを更新時刻だけで見ていたためで、大きさとファイル番号 (inode・ボリューム) も見るようにしました。読む手間は変わりません (`stat` 1 回)。同じファイルを同じ大きさで書き換えて更新時刻を手で戻したときは、引き続き見分けません。
