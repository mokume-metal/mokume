`loadImage(_:)` に例と絵が付きました。例はその場で小さな PNG を一時ディレクトリへ書き出してから読み、等倍で置きます。書き出す絵の縦横だけを変えた 3 枚で、読んだ絵がファイルの画素数のまま置かれ、`width` と `height` もその数になることが見えます。

`requestImage(_:)` は、届いた絵の見え方が `loadImage(_:)` と同じなので、そちらの絵を見るよう案内しています。何枚目のフレームで届くかは絵の大きさとフレームの間隔で変わるため、この口だけの絵は付けていません。

`loadImage(_:)` の説明には、`/` で始まる名前はその場所だけを読むことも書き足しました。
