**`createShape { }` の中で、先に置いた描き場所を描き換えたときに、置いた側が描き換える前の絵の写しを持てないと、組み立てた形が空になって「mokume の不具合」と名乗る注意が出る不具合を直しました。** 同じフレームで `image(layer)` と置いたものを、組み立ての中で `layer.beginDraw()`〜`endDraw()` で描き換えると、置いた側は描き換える前の絵の写しを 4 枚まで持ち、越えた分と写しを用意できなかった分は置いた側を描き切って、先に置いた所を置いた時点の絵のまま守ります。このとき、組み立てた分まで一緒に描き切られて形が空になり、組み立てた図形がフレームに出ていました。いまは描き切るのを組み立ての前に置いた分だけにして、組み立てている途中の分は残すので、形は中で描いたものを持ち、組み立てた図形はフレームに出ません。描き切りの後に組み立てたものも形に入ります。
