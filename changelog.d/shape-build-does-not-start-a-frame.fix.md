描き場所の `createShape { }` の中で、その描き場所のフレームを始める (`beginDraw()` を呼ぶか `draw { }` を開く) と、**それまでに組み立てたものが捨てられて形が空になり**、「mokume の不具合なので報告を」という注意 (フレームの外で置いたものを捨てた) まで出ていたのを直しました。`Canvas` を直に作った面が `beginDraw()` で開いたフレームの中で組み立て、その中でもう一度 `beginDraw()` / `draw { }` を呼んだときも、開いていたフレームが閉じ忘れとして捨てられていました ([#2201](https://github.com/mokume-metal/mokume/issues/2201))。

いまは組み立ての中では、組み立てている面のフレームを始めません。1 度注意して、`beginDraw()` は何もせず (閉じるフレームの無い `endDraw()` も何もしません)、`draw { }` は閉包を組み立ての続きとして走らせて中で描いたものを形に入れます。形は組み立てたものを持ち、開いていたフレームはそのまま続きます。

描き場所の組み立ての中で**本体の**面のフレームを始める (`canvas.beginDraw()` / `canvas.draw { }`) と、本体のフレームの始まりが描き場所の開いたフレームを閉じ忘れとして捨て、形が空になる道は残っています ([#2509](https://github.com/mokume-metal/mokume/issues/2509) で扱います)。

フレームを開いていない描き場所で、組み立ての中で何も描かないうちに `beginDraw()` / `draw { }` を呼んだときは、これまではそこでフレームが開き、組み立ての出口で閉じていましたが、これからは開きません。描き場所に描くフレームは、組み立ての前か後で開いてください。
