**ループ中の `mousePressed()` などで書いた変換・光・切り抜きが、同じフレームの `draw()` に効かなくなりました。** これまでは、`mousePressed()` で `translate(50, 0)` と書くと、押したフレームだけ `draw()` の絵が 50 画素右へずれていました (`lights()` や `clip()` も同じで、押したフレームの `draw()` に光が当たったり、切り抜きで欠けたりしました)。`draw()` の頭で変換が既定へ戻る Processing・p5.js とは違う結果で、`noLoop()` で止めている間のコールバックとも結果が割れていました。ループ中 (と、`redraw()` を頼んだ後) のコールバックも、1 つごとに、書いた変換・光・視点・切り抜き・材質・影・周囲・効果を抜けるときに戻すようにしました。コールバックの中で置いた図形は、これまでどおり書いた変換・光・切り抜きで描かれます。塗りや線などの描き方と乱数の種は、これまでどおり戻りません。コールバックで書いた変換などが同じフレームの `draw()` に効くことに頼っていた作品は、絵が変わります。変換などは `draw()` の中で毎フレーム書いてください。
