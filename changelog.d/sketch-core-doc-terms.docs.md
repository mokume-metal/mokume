スケッチの基本の API (`Sketch` プロトコル・`SketchSettings`・時計とフレームの時刻・ファイルのドロップ・全画面) の説明を、一般的な技術用語で書き直した。Xcode のクイックヘルプとリファレンスで、「口」「手本」「落とす」「細かさ」「名乗る」「走っている」「作品」「足し込む」などの独自の言い回しが、API・Processing・ドロップ・ピクセル密度・報告する・実行中・スケッチ・加算するといった通常の用語になる。API の名前と挙動は変わらない。
