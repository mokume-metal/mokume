参照の面の 2D 図形の説明に、**実行結果の絵**が付いた。`rect` / `square` / `circle` / `ellipse` / `arc` / `triangle` / `quad` / `point` / `line` と、座標の読み方を決める `rectMode` / `ellipseMode` に、引数を 1 つずつ動かした例が並ぶ (`arc` には動くものも 1 本)。

絵は説明文の中のコードから機械が撮って書き戻すので、例を書き換えたのに絵が古いままになることは無い。
