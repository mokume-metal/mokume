エージェントの窓口 (MCP) が、応答を JSON にできないときに黙らなくなった。これまでは空行を書いていたので、繋いでいる側からは「応答が来ない」と見分けが付かず、呼び出しが返らないまま待つことになっていた。いまは JSON-RPC の失敗 (`-32603`) として返る。

**窓口が落ちる道も塞いだ。** 応答に JSON にできない値 (非数など) が混ざると、`JSONSerialization` は Swift の error ではなく ObjC の例外を出すため、握っていたつもりの `try?` を素通りして**窓口ごと終了していた**。値の形を先に見るようにした。

`mokume run` が、スケッチの終了コードを引き継ぐときに理由も名乗るようになった。0 以外で終わったスケッチについて「道具が足した失敗ではない」と 1 行を標準エラーへ出す。終了コードはこれまでどおりスケッチのものがそのまま返る。
