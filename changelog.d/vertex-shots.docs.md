頂点列の 10 口 (`beginShape` / `vertex` / `bezierVertex` / `quadraticVertex` / `curveVertex` / `curveDetail` / `curveTightness` / `beginContour` / `endContour` / `endShape`) に、引数を 1 つずつ動かした例と絵を付けた。`beginShape` の 4 つの読み方と `endShape` の 2 つの閉じ方は、**同じ点の並び**を渡した絵を並べてある。

あわせて `curveTightness` の説明を直した。「大きくすると曲がりが緩くなる」は意味が逆にも取れたので、**1 で点と点が直線で結ばれる**ことを明記した。
