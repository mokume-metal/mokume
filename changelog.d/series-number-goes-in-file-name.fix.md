連番の書き出し (`beginRecord("…/f-##.png")`・`mokume render --out`) で、置き場のフォルダの名前に `#` があっても、番号がファイル名の `#` に入るようにした。これまではパス全体の最初の `#` を番号の場所に読んでいたので、`take#1/f-##.png` へ撮ると `take#1/` は空のまま、隣に `take01/`・`take11/`… ができて 1 枚ずつ別のフォルダへ書いていた。`mokume render` は `--out` を打った場所から絶対パスにして読むので、`take#1/` の中で `--out still.png` と打つだけで同じことが起き、断られずに 0 で終わっていた。いまは使い方の誤りとして止まる。`--out` がフォルダを指す綴り (`take#1/`・`out-##/` のように末尾が `/`) のときも、打った場所に拡張子の無い `take01`・`take11`… を並べずに、使い方の誤りとして止まる。

フォルダの名前にだけ `#` を置いた指定 (`beginRecord("out-##/frame.png")`) は、ファイル名に番号の入る場所が無いので、撮り始めずに知らせるようになった。1 枚ずつ別のフォルダへ書くこの形は説明が約束していなかったもので、連番にするには `#` をファイル名へ移す (`"out/frame-##.png"`)。
