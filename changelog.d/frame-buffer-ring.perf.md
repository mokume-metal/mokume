**フレームの描き切りが、GPU の仕事が全部終わるのを待たなくなりました。** [前の版](https://github.com/mokume-metal/mokume/issues/727)で描き切り自体は待たなくなっていましたが、次のフレームが図形を書き込む置き場は 1 本しか無かったので、書き始める前に結局 GPU の完了を待っていました。置き場を 3 組の環にしたので、待つのは「2 フレーム前の自分」だけになり、その間 CPU は次のフレームを組み立て、GPU は前のフレームを描き続けます。

**効くのは、置いた描き場所 (`createGraphics`) を使う絵です。** 描き場所を N 枚重ねるとフレームごとに N+1 回待っていたのが 0 回になります。手元の計測 (1920x1080・240 フレーム) では、640x360 の描き場所 3 枚に図形を描いて重ねる絵が 0.80 ms → 0.32 ms/frame になりました。描き場所を使わない絵でも 1 割ほど縮みます (図形 4000 個 + 全面の半透明 60 枚 + 効果 2 段で 3.43 ms → 3.13 ms/frame)。

**書き味は変わりません。** 絵は 1 画素も変わらず、画素や計算の結果を読む口・数の並びや粒や画像へ書く口は、これまでどおり触る直前に自分で待ちます。
