`mokume run --record` の記録が、読んだローカルの資源 (画像・文字やデータ・SVG・モデル・フォント・音・`.metal` の断片) の中身のハッシュを持つようになり、`mokume replay` で流したときに中身が違う資源を「再現を保証しない」と名前つきで名乗る。

記録した後に `dot.png` を描き直してから流すと、最後の 1 行と `report.json` の `unreproducible` に `dot.png` が載る。照合の一致 (`matched`) は絵だけで決まり、資源の違いだけでは変わらない。記録の途中で同じ名前の中身が変わったときは、記録の側が名乗る。ハッシュを取るのは記録か再生をしている実行だけで、ふだんの実行の読み込みは遅くならない。URL から読んだ本文・カメラ・動画は対象外 (これまでどおり別の理由で名乗る)。この欄を持たない前の記録も、そのまま流せる。
