`Vector2` の `length` が、成分が約 1e-23 を下回る小さな値でも 0 にならず、正しい長さを返すようになった。`mag()`・`dist()` と同じ答えになる。

これまでは `Vector2(1e-30, 1e-30).length` が 0 で、`mag(1e-30, 1e-30)` は 1.414e-30 と、値型と関数が食い違っていた。あわせて、そのような小さな値の `normalized()` は自身を返さず、長さ 1 の向きを返す。0 を返すのは 0 ベクトルだけになった。速さを毎フレーム縮めて止める作品では、速さが 1e-45 付近まで落ちる手前の間、`velocity.normalized()` が (0, 0) へ向かわず長さ 1 を返し続ける。止めたいときは `length` を小さなしきい値と比べる。`mag()`・`dist()` は、2 乗の和が 2^-100 以上 2^100 未満の普通の値では答えのビットが変わらず、その外では数 ulp 動くことがある。
