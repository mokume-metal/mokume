`loadModel` で読んだモデルが、面の向きを書いた面と書かない面の混ざったファイルでも、書かない面を正しく光らせるようになった。向きの有無を、モデル単位の 1 つの印ではなく角ごとに決める。

- **OBJ**: `vn` のある面と無い面が混ざると、`vn` の無い面の向きが形から求められず、既定の (0, 0, 1) を向いていた。いまは形から求め、どの面にも `vn` が無いファイルを読んだときと同じ向きになる。番号が範囲の外の `vn` を書いた角も同じ
- **STL**: `facet normal 0 0 0` の面は両面として扱う約束だが、同じファイルに向きを書いた面が 1 つでもあると片面になり、巻き方が見る側と逆なら真っ黒になっていた。いまは `0 0 0` の面だけが両面になり、書いた面は片面のまま

- **OBJ の `vn 0 0 0`** (長さ 0 の向き): 書いた向きとして読み、形から求めず両面にもならなかったので、その面は光を受けず塗りの色そのままで描かれていた。いまは STL の `facet normal 0 0 0` と同じく書いていない向きとして形から求め、両面にする

どの面も (長さのある) 向きを書いている・どの面も書いていないファイルの絵は変わらない。
