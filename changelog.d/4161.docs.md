`mokume help run` の `--record` の説明と、リプレイの記録・報告の JSON Schema (`replay-record.schema.json`・`replay-report.schema.json`) に、記録と報告には読んだファイルの名前・ドロップや選択したファイルのパス・記録の場所が絶対パスならそのまま (ホームディレクトリとユーザー名ごと) 載るので、人に渡す前に中を見る、と書いた。記録の中身と形式は変わらない。
