曲線の縁の濃さについて、v0.34.0 のノートの「円・楕円の縁の濃さが画素ごとに面積と一致する」を訂正します ([#3493](https://github.com/mokume-metal/mokume/issues/3493))。曲線の縁は、画素の中心での距離と勾配から作った接線の半平面で数える近似なので、凸の縁 (円・楕円・扇の外縁・角丸の角) は面積より明るく、凹の縁 (輪郭の帯の内縁) は同じ大きさで暗く出ます。差は描く画素での曲率半径 R に対して約 0.12 / R までで、半径 3 で最大約 0.037 (9/255 ほど)、半径 7 以上は 0.02 の内です。

絵は変わりません。測ったのは円 (一様な拡大) だけで、一様でない拡大と楕円 (距離場そのものが近似なので別の誤差が重なります) は測っていません。`point()` と丸い端の線の端は、これまでどおり線形の渡しで、この話の外です。
