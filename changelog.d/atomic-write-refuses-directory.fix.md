つまみの保存や応答など、`.mokume/` に JSON を置く処理が、置く先に同じ名前のディレクトリがあると、そのディレクトリを中身ごと消してファイルに置き換えていた不具合を直した。いまは置き換えずに失敗し、「Is a directory」と名乗る (各処理の警告の出し方は変わらない)。

同じ根の兄弟も直した: 動画の書き出し先 (`record` の `.mov` のパス) がディレクトリを指していると、それを中身ごと消していたのを、消さずに「Is a directory」で失敗するようにした。撮り始める前の観測の掃除も、目録や絵の名前をディレクトリが使っていれば、消さずに残す。
