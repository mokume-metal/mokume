公開 API の一覧に、**同名で引数の型が違う宣言**が漏れなく載るようになりました。これまでは名前だけで 1 本に畳んでいたため、`background(_:)` のように色を渡す形と周囲を渡す形の 2 つがあるものは片方しか載らず、一覧だけを読んで書く相手にはもう片方が存在しないように見えていました。同じ畳み込みが説明文の重複検査の目も塞いでいたので、`Canvas` 側に重ねて置かれていた説明文 32 本を落としました — 意味の説明の正本はスケッチから直接呼ぶ側にあります。
