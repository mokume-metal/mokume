図形に絵を貼る口 (`texture(_:)` と `noTexture()`) と、画素を読み書きする口 (`pixels` と `loadPixels()`) に、例と絵が付きました。

`texture` は、同じ絵が四角・箱・球でどう貼られるか、`fill` が色掛けになること、線には貼られないこと、貼った描き場所を描き換えても先に置いた形が変わらないことが、引数を 1 つずつ動かした絵で見えます。`noTexture()` は、`push()` / `pop()` の中で呼んだときに `pop()` で貼る絵が戻ることも並べました。`pixels` は、読んで書き換える・書いた画素を読み直す・半透明の画素を読んで書き戻しても色が沈まないことを絵にしています。

`loadPixels()` は、呼ぶと**そこがフレームの区切りになる**ことを、床を置いたあとに呼ぶ・呼ばない 2 枚で見せています。呼ぶと床はそこで描き切られるので、そのあとに置いた球の影が床に落ちません。

`loadImage(_:)` と `requestImage(_:)` は読む先の画像ファイルが要るため、絵は付いていません。
