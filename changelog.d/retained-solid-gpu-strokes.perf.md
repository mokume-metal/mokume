`createShape` で保持した形の中の組み込み立体 (`sphere`・`box` など) の線を、置くたびに CPU で組み直すのをやめ、その場で描くときと同じく GPU で組むようにしました。線だけの球を保持して 30 か所に置く場面で、1 フレームが約 9.8 ms から 0.47 ms に、200 か所なら約 61 ms から 1.75 ms になります。対象は不透明・既定の折れ目 (miter)・通常の混ぜ方・絵も断片も無しで記録した線で、それ以外は今までどおり CPU で組みます。

これで保持した形の線は、同じものをその場で描いた線と同じ絵になります。以前は視点を回すと、線の縁の 1 画素がその場で描いた線と違うことがありました。
