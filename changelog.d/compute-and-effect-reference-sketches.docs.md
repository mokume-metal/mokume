計算と粒と効果の参照スケッチを 3 本足しました。`swift run reference-sketches field-and-flow` で GPU が毎フレーム書いた場を全画面 1 枚の矩形として描く様子 (印は 30 フレームに 1 度だけ CPU へ引き戻して置いています) が、`sparks-and-forces` で 4 つの力の足し算から渦の円盤が現れる様子が、`glow-and-detail` で描く細かさを半分にしたまま効果を 3 段重ねた絵が見られます。
