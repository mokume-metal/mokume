半透明の線 (`stroke(255, 0, 0, 128)` など) や `blendMode(.add)` などの下地を読む混ぜ方で引いた線が、`beginShape()` の角・端・曲線の継ぎ目で濃くなっていたのを直しました。`shader()` や `texture()` を付けた `rect` / `ellipse` / `arc` / `line` も、角や細長い楕円の上下の弧の重なりが濃くなっていました。凹んだ `quad` の向かい合う辺の重なりも同じです。線を組む部品 (帯・角・端・継ぎ目の円板) を重ねたまま積んでいたためで、先に置いた部品との重なりを引いて積むようにしました。線の形と塗る範囲は変わりません。`beginShape()` で並べた形の線のうち、線に沿って太さより離れた部分が重なる所 (自己交差・細長い形の向かい合う辺など) は、これまでどおり別々の線が重なるのと同じく重ねて混ぜます。
