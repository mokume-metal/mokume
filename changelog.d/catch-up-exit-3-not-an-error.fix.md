`make catch-up` が、**打つ意味が無いとき (待つのが正解の場面) にエラーを出さなくなった**。先に別の描画 PR が居る・その PR は描画に触れない・Draft である、といった「まだ打たなくてよい」を伝える終了は、これまで `make: *** [catch-up] Error 3` として赤く出ていた。待てばよいだけの状態を、壊れているものとして受け取っていたことになる。

いまは番号を名指しした案内だけが出て `make` は正常終了する。本当に途中で止まったとき (衝突・検査の失敗・報告が付かない) は従来どおり赤くなる。
