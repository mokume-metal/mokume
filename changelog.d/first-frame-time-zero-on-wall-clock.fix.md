**窓で動かしているときも、最初のフレームの `time` が 0、`deltaTime` が 1 フレームぶん (60 fps なら 1/60 秒) から始まるようになりました。** これまでは、アプリの起動と `setup()` にかかった時間が最初のフレームの `time` に乗り (`setup()` の計算に 2 秒かかれば約 2.0 から始まる)、最初の `deltaTime` も上限 (目標の 10 フレームぶん) まで長くなっていました。書き出し (`mokume render`) の時刻は前から 0 で始まっており、変わりません。`setup()` の長さは機械ごとに違うので、`time` から導いた動きの位相が機械ごとにずれていたのも揃います。

乗らなくなったのは `setup()` の中で済む計算の時間です。`setup()` で置いた図形・画素・背景は最初のフレームへ持ち越されてその中で組まれ、最初の `draw()` の重い準備もその中で走るので、それらの時間はほかのフレームと同じく 2 枚目の `deltaTime` に (上限まで) 乗ります。2 枚目の長い `deltaTime` を `min(deltaTime, …)` で抑えている書き方は、そのまま残してください。`setup()` で `jumpTime()` した最初のフレームの `time` はこれまでどおり飛び先の秒で、`jumpTime()` / `pauseTime()` した最初のフレームの `deltaTime` は 0 です。
