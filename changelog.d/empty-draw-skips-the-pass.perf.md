**何も描かないフレームが、GPU に空のパスを投入しなくなりました。** `draw { }` の中で図形も背景も効果も計算も置かないフレームは、描く先へのパスもコマンドの投入も作りません。release の計測で、空の `draw` が返るまでの時間が約 0.013 ms から約 0.002 ms に、投入は 1 フレーム 1 回から 0 回になります。背景・書き込んだ画素・効果・計算・画素の読み戻しのあるフレームは、これまでどおり投入します。`pixelDensity` を下げた面は、拡大が空間方向 (`.spatial`) で、出す先が既に描く先を広げた最新の絵のときだけ省きます。時間方向 (`.temporal`) は、前のフレームと混ぜて揺らすので毎フレーム拡大します。絵は変わりません。
