形で切り抜く `clip { }` が付きました。`clip { circle(mouseX, mouseY, 220) }` と書くと、閉包の中で描いた形の塗りの内側だけに以後の描画が残り、円の窓から絵を覗くような定番が書けます (手本は p5.js 2.x の `clip(callback)`)。窓は呼んだ時点の変換で読み、`pop()` か `noClip()` まで効きます。`clip { }` を重ねると窓は交わり、矩形の `clip()` は前の窓を置き換えます。窓を決めるのは 2D の形の塗りだけで、線・字・画像・立体・`shader()` の形は窓に入れずに 1 度警告します。

あわせて、`rotate()` や `shearX()` の後で呼んだ矩形の `clip()` が、回した・傾けた矩形そのもので切り抜くようになりました。これまでは 4 つの角を囲む面に沿った矩形で切り、警告していました。囲む矩形の隅に描かれていた画素は、今後は描かれません。
