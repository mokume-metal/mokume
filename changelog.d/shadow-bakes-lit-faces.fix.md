**床に接して置いた組み込みの立体 (`box` / `sphere` / `ellipsoid` / `cylinder` / `cone` / `torus`) の影で、接した縁に沿って光が漏れていた**のを直しました。影を焼き付けるとき、これらの立体だけ光を向いた面を捨てて奥の面を焼いていたので、接した縁の近くでは焼き付いた奥行きと床の奥行きの差が縁の余裕 (`shadowBias`) より小さくなり、影が形から離れて見えていました。漏れの幅は焼く範囲 (`shadowRange`) に比例するので、範囲を広げた作品ほど目立ち、範囲を大きく広げると影そのものも痩せていました。いまは組み込みの立体も、読み込んだモデルや頂点で組んだ形・保持した形と同じく光を向いた面を焼くので、同じ箱なら作り方によらず同じ影を落とします。代わりに、組み込みの立体の明るい側にも、モデルや頂点で組んだ形と同じ自分の影の縞が出ることがあります — `shadowBias` を 0 近くまで小さくしたときと、`shadowDetail` を焼く範囲に比べて大きく落としたときです (縁の余裕は焼く範囲に比例する量で、焼き付け先の画素の粗さには比例しないため)。縞が出たら `shadowBias` を少し広げるか、`shadowDetail` を上げてください。既定の設定で浮かせて置いた形の見た目は、ほとんど変わりません。
