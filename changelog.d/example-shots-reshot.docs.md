説明文の例の絵を、いまの描画で撮り直しました。9 月前半に撮ってから描画の修正が続いていて、数値で書いた色の扱い・影・文字の折り返し・太い線の曲線などが、貼ってあった絵と合わなくなっていました。

`ellipsoid(_:_:_:detail:)` の 2 つの例にも、他の立体と同じく絵が付きました。

`shadowRange(_:)` と `shadowDetail(_:)` の絵の説明を撮り直した絵に合わせ、`shadowDetail(_:)` には、画素数を落としたときに球の上に出る粗い段が `shadowBias(_:)` の余裕とどう関わるかを書きました。
