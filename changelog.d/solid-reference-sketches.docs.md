立体の参照スケッチを 3 本足しました。`swift run reference-sketches solids-and-light` で組み込みの立体 6 種・光 4 種・影が回りながら見え、`materials-and-surroundings` で質感 4 つの効き方と周囲の入れ替わりが、`crowd-and-model` でまとめ描き・頂点を並べた自由な立体・読み込んだモデル・引きずって回す視点が見られます。あわせて `--render <置き場> --frames <枚数>` で連番の書き出しができるようになりました (立体は静止画だと向きが読めないため)。
