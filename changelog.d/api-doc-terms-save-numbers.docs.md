保存 (`save`・`beginRecord`・`endRecord`・`beginSVG`) と数の関数 (`map`・`lerp`・`constrain`・`smoothstep`・`mod` ほか) の説明文を、一般的な技術用語で書き直した。クイックヘルプと DocC に出る文面が変わる。「手本」は Processing、「頼む」は要求する、「綴り」は表記、「継ぎ目」は接合部、「畳む」はラップする・まとめる、「書き損じ」は書き込み失敗、「黙って」は警告なしにと書く。挙動は変わらない。
