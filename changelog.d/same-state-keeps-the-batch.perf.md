同じ値を設定し直しても描く回数が増えなくなり、部品ごとに `shader.set()`・`clip()`・`camera()`・`shininess()` などを呼ぶスケッチが速くなりました。部品ごとに同じ値を設定し直す 256 個の四角形で、描く回数が 256 回から 1 回になり、`draw()` が返るまでの時間は 1.16 ms から 0.07〜0.14 ms に (Apple M3 Max)。同じ `clip()` を呼ぶ 64 個の箱は 0.12 ms から 0.03 ms です。値が本当に変わるときは今までどおり、その時点までに置いた図形を前の値で描きます。`+0` と `-0`、中身の違う `NaN` は別の値として扱うので、絵は変わりません。
