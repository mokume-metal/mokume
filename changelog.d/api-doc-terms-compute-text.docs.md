計算 (`makeComputation`・`dispatch`・`read`) と文字 (`text`・`textFont`・`textBounds` ほか) の説明文を、一般的な技術用語で書き直した。クイックヘルプと DocC に出る文面が変わる。「断片」はシェーダ、「入口」はエントリポイント、「束ねる」はバインド、「頼む」は呼ぶ・指定する、「控え」はキャッシュ、「焼き場」はアトラス、「墨」はインク範囲、書体の「面」はフェイスと書く。挙動は変わらない。
