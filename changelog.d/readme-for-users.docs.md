[README](https://github.com/mokume-metal/mokume#readme) を利用者向けに組み直した。冒頭に実行結果の絵 1 枚と、何が書けるかの短い紹介が出るようになり、GitHub だけを見る人にも入口の 1 枚 (<https://mokume.org>) と同じことが伝わる。

あわせて、mokume 自体を触る人向けの手順 — このリポジトリを clone して `mokume-cli` を作る・`--local` でスケッチに手元のライブラリを引かせる — を [CONTRIBUTING.md](https://github.com/mokume-metal/mokume/blob/main/CONTRIBUTING.md#手元で作る) へ移した。`brew install` した利用者が読む面と、リポジトリを触る人が読む面が分かれる。
