窓を触った操作がスケッチへ届くようになった。窓の中でマウスを動かす・押す・離す・引きずる・スクロールする・キーを打つと、そのフレームの `draw()` から `mouseX` / `mouseY` / `isMousePressed` / `dragX` / `scrollY` / `key` などで読める。**外から送られた出来事と同じ合流点へ入る**ので、外から動かして確かめたことが人が触ったときにもそのまま成り立つ (`orbitControl()` が窓の中で効くようになったのもこれ)。読める座標は**窓の大きさによらず描く解像度の座標系**で、窓を大きくしても縮めても同じ場所は同じ数で読める。縦横比が合わないときに出る帯の上を指すと座標は面の外を指し、**負や幅超えの値になる** — 丸めていないので、面の外を面の外として扱える。
