粒 (`emit` / `particles`)・数の並びへの書き込み (`Numbers.set` / `fill`)・書き換えた画像の送り (`Image.set` / `write` / `fill` の後に描く) が、書くたびに GPU の完了を待たなくなった。書いた値は描き切りが GPU へ届けるので、これらを毎フレーム使うスケッチでも、CPU が次のフレームを組むあいだに GPU が前のフレームを描き進められる。書いた直後に `read()` で読めば書いた値が返り、描いた絵も変わらない。

ひとつだけ見え方が変わる。画像を置いたあと、置き直さずに同じフレームで画素を書き換えると、そのフレームには書き換えた後の絵が出る (これまでは書き換える前の絵が出ていた)。
