参照の面の索引を、型の一覧から**書く人がやりたいこと → その口**の並びに組み替えた。面の最初の画面から `circle` や `fill` へ 1 手で届き、一行説明もその場に出る。同じ束に並んだ口どうしは互いの「See Also」にも現れる。

あわせて、道具・エージェント・実行の土台だけが触る型 16 本を面から外した。**公開している API は 1 つも変わっていない** — 版ごとに配る公開 API の一覧は今までどおり全部を載せるので、道具・エージェント・外のパッケージから使えるものは変わらない。
