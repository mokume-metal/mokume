文字の 13 口 (`text` の 2 つ / `textSize` / `textFont` / `noTextFont` / `textStyle` / `textAlign` / `textLeading` / `textWidth` / `textAscent` / `textDescent` / `textWrap` / `textOutline`) に、引数を 1 つずつ動かした例と絵を付けた。位置を決める口は、基準になる線や枠を絵の中に描いてある — `textAlign` は同じ 1 本の線に対する 3 通り・4 通りを並べ、`textAscent` / `textDescent` / `textWidth` は返る値で引いた線と字が合うことを見せる。
