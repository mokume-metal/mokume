窓を開く大きさをスケッチから選べるようにしました。`SketchSettings` の `windowScale` に、描く 1 画素を窓の何点にするかを書きます。`SketchSettings(width: 320, height: 180, windowScale: 4)` なら 320×180 の画素絵を 1280×720 点の窓で拡大して見せ、`windowScale: 1` なら Processing の `size(1280, 720)` と同じ 1280×720 点で開きます。指定しなければこれまでどおり描く大きさの半分 (0.5) で開きます。描く画素の数と書き出す絵は変わりません。

窓が覚えていた大きさのせいで、描く大きさを変えても前の窓の大きさで開いていたのも直しました。開く大きさの指定 (描く大きさ × `windowScale`) が前と変わったときは、覚えた大きさと位置を捨てて新しい指定で開きます。変えていなければ、手で広げた大きさと置いた位置がこれまでどおり戻ります。この版へ上げて最初に開くときは、指定を覚えていないので一度だけ指定の大きさで中央に開きます。

`mokume watch` の作品の窓も、直に走らせたときと同じ大きさで開くようになりました (これまでは描く大きさによらず 480×270 点でした)。道具とライブラリの両方をこの版へ揃えると効きます。0 以下・無限大・NaN の `windowScale` は起動のときに断り、画面に収まらない大きさは縦横比を保って画面に収まるまで縮めて開きます。
