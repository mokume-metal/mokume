自分で書く塗り (`makeShader` / `shader(_:)` / `resetShader()`) と効果 (`effects(_:)` / `makeEffect`) に、例と絵が付きました。

塗りは、渡す値を 0・0.5・1 と変えると縞の濃さが変わり 0 では組み込みの塗りと同じ色になること、同じ断片が四角にも光を当てた箱にも効くこと、描き場所と画素から作った絵の両方を渡して面の中の位置で読めること、秒数で縞が流れること (動く絵) が、引数を 1 つずつ動かした絵で見えます。`shader(_:)` は当てる前に置いた図形が組み込みの塗りのまま残ることと、`setup()` で 1 度当てた断片がフレームを越えて効くことを、`resetShader()` は戻した後の図形が当てる前と同じ色になることを見せています。

効果は、ぼかし → にじみ → 周辺減光を掛けた絵のほか、周辺減光と反転を並べる順を入れ替えると四隅が明るくなるか暗くなるかが変わること、フレームの途中で読んだ画素にはまだ効果が掛かっていないこと、`background()` を 1 枚目だけ呼んで描き足しても効果が重なっていかないこと (動く絵) を並べました。`makeEffect` は、行ごとに横へずらして読む効果の振れ幅を値で変える絵と、揺れが時間とともに流れる動く絵です。

ファイルから読む `loadShader` と `loadEffect` は書き方が同じなので、文字列から作る口の例と絵を指しています。
