**本体が計算する値が、`mokume bundle` (release) と手元の `mokume run` (debug) で同じになりました。** これまでは release で組むと、回した立体・球や円柱・定数で書いた周囲の色 (`.sky` など) の縁の画素が、数画素だけ 1 階調ずれることがありました。最適化が本体の `sin` と `cos` を 1 回の計算に畳んだり、定数を渡した `pow` などを組むときに計算したりして、値がごく僅かに変わっていたためです。本体の計算 (音の合成と解析を含む) はどちらの構成でも同じ値になるようにしました。ただし、スケッチに自分で書いた `sin` や `pow` は作者のパッケージの構成で組まれるので、その値が構成で 1 ULP 変わり、絵が数画素ずれることは残ります。
