**`mokume bundle` で配った app の絵が、手元の `mokume run` で見た絵と画素単位で同じになりました。** これまでは release で組むと、回した立体・球や円柱・定数で書いた周囲の色 (`.sky` など) の縁の画素が、数画素だけ 1 階調ずれることがありました。最適化が本体の `sin` と `cos` を 1 回の計算に畳んだり、定数を渡した `pow` などを組むときに計算したりして、値がごく僅かに変わっていたためです。本体の計算はどちらの構成でも同じ値になるようにしました。スケッチに書いた `sin` などは作者のパッケージの構成で組まれるので、そちらの値は変わりえます。
