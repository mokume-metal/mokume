mokume

Creative coding for Swift + Metal.

何ができるか

2D の図形と文字、立体と光、粒と力、画素の読み書き、GPU の計算とポストエフェクトを、 1 つの Sketch の中で書く。座標は出す細かさのままなので、 描く解像度を落としても本文は変わらない。

走らせたスケッチは外から観測できる。撮る・作り直しの結果を読む・入力を送る、が エージェントからも同じ口で使える。

入れる

macOS 26 (Tahoe) 以上・Apple Silicon 専用。

brew install mokume-metal/tap/mokume

Homebrew を使わない入れ方と、このリポジトリから道具を作る手順は README にある。

最初の 1 本

mokume new my-sketch
cd my-sketch
mokume run             # 作って走らせる
mokume watch           # 保存したら作り直して差し替える

できるのは、そのまま動く 1 ファイルのスケッチ:

import mokume

@main
final class MySketch: Sketch {
    var settings = SketchSettings(width: 960, height: 540, title: "my-sketch")

    func draw() {
        background(.display(red: 0.06, green: 0.07, blue: 0.09))
        fill(.display(red: 0.95, green: 0.45, blue: 0.2))
        let angle = time * 0.8
        circle(width / 2 + cos(angle) * 160, height / 2 + sin(angle) * 120, 80)
    }
}
